## Travail effectue

Le travail est volontairement limite au salon et a sa verification. Aucun fichier `src/`, aucune loi de conduite et aucun module FERRO n'ont ete modifies.

### Salon reseau

- La premiere trame WebSocket lue avec les en-tetes HTTP est maintenant traitee : une demande de creation ou de connexion n'est plus perdue dans `head`.
- Une fermeture TCP sans message WebSocket libere immediatement le salon et previent les autres joueurs, au lieu d'attendre les battements de vie.
- Le parseur arrete toute execution des que la connexion ferme. Une commande coalescee apres une fermeture ou une erreur ne peut plus creer de salon fantome.
- La limite de 64 Kio s'applique au message fragmente complet, pas seulement a chaque fragment. Le nombre de fragments est borne a 1024, y compris les fragments vides.
- Les continuations orphelines, les messages imbriques, les bits reserves, les opcodes inconnus et les controles mal formes sont refuses.
- Les messages texte et les raisons de fermeture sont controles en UTF-8 strict, apres assemblage des fragments. Les caracteres multioctets coupes entre trames restent acceptes.
- Les negotiations invalides sont refusees avant d'occuper une place. Les minuteries et tampons sont liberes a la fermeture, avec un delai maximal pour un pair qui n'acquitte jamais.
- Un relais exige que la connexion appartienne encore effectivement au salon, meme si un ancien code est reutilise.

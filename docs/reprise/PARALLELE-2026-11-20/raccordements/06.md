# Raccord 06 → 00 : pluie extérieure depuis abri

Statut : module qualifié avec PhysX ; compositing raster à recevoir avant intégration.

## Sources et contrat

`B.meteo.creerPluie(canvas).dessiner(meteo, camera, dt, options)` accepte
`options.circuit`, `options.physique` et `options.palier`. Les deux premières
références sont celles de la course ; le masque emploie ses solides réels.
Le résultat réutilisé contient les compteurs `spatiaux`, `abrites`,
`occultes` et `rayons` en plus des compteurs historiques.

`B.meteo.abriCouverts(circuit, position, physique)` complète l'abri logique
par les débords de toiture réellement présents dans PhysX.

Le patch `06-jeu.patch` conserve la pluie mondiale lorsque la caméra entre
sous un toit. La neige continue de couper la pluie liquide. `abri` protège
la visière et les embruns ; les gouttes déjà présentes sèchent normalement.
Le champ `S.pluieImage` expose les statistiques de cette vue pour le banc.
J1 et J2 conservent chacun leur Canvas et leurs tampons.

## Application ultérieure

Réconcilier le patch avec le dernier `src/jeu.js` qualifié de 00 ; ne pas
réintroduire ses lignes anciennes ni les changements concurrents de rétros.
Le patch porte uniquement sur les lignes d'appel météo dans `dessinerMeteo`.
Aucun module nouveau à ajouter à `construire.py` et aucun import FERRO.

La CI dédiée applique ce raccord dans sa copie avant reconstruction et
captures. Cette reconstruction est un artefact de qualification local à la
branche ; elle ne réserve aucun numéro de version de livraison.

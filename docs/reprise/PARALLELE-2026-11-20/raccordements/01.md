## Choix Troll et démarrage commun

Valeurs canoniques : gestes `majeur`, `poing`, `salut` ; klaxons `classique`, `ancien`, `mariage`. Les normaliseurs exportés ramènent une valeur inconnue à `majeur`/`classique`.

```js
reglages.trollPilotes = [
  { geste: 'majeur', klaxon: 'classique' },
  { geste: 'majeur', klaxon: 'classique' }
];
```

Les indices désignent les places locales, pas les identifiants de voiture. Après création de `S.locaux`, appeler `configurer(E, S.locaux[n], choix[n])` pour chaque humain local. La configuration est copiée ; une mutation ultérieure du menu ne change pas le geste en cours. Le patch utilise `choixTrollLocaux()` fourni par 03, ou `reglages.trollPilotes` en repli. La préécoute explicite du menu reste le raccord de 03 via `son.klaxon` après interaction.

`demander(E,id,appuye)` traite le front d'appui existant et ne joue aucun son. L'événement naît seulement au démarrage effectif du geste : une demande différée par un rapport attend au plus 0,65 s ; une demande refusée ne produit pas de klaxon. Le délai manuel est de 2,5 s.

Préallouer une sortie par séance, puis consommer immédiatement après `actualiser`, avant toutes les vues J2/J1 et rétroviseurs :

```js
const sortie = { sequence: 0, pilote: -1, geste: null, klaxon: null, instant: 0, cote: 0 };
B.expressionsPilote.actualiser(E, course, poses, tRendu, demo);
while (B.expressionsPilote.consommerEvenement(E, sortie)) {
  // Consommer ici une seule fois ; la sortie sera réécrite au prochain événement.
}
```

Le patch fait une tentative `son.evenement('troll', audio)` par événement avec un objet audio réutilisé. La spatialisation prend le joueur local le plus proche ou le sujet de la démo. La file est vidée même hors écran, sans audio ou si l'audio refuse la lecture ; aucun klaxon n'est différé jusqu'au retour dans la course. Les lectures de pose restent pures.

La file contient N indices et N événements préalloués, N étant le nombre de pilotes (1 à 64). L'ordre est celui des démarrages acceptés ; `sequence` est globale et croissante pendant la vie de l'état, même après remise à zéro de son temps. Une nouvelle actualisation efface les événements non consommés de l'image précédente. La saturation refuse avant geste, son ou tirage aléatoire. L'API auxiliaire `consommer(E,id)` partage le même marquage de consommation ; le raccord de jeu doit utiliser l'API canonique ci-dessus.

## IA, audio et réseau

Activer les IA en course par `creer(nombre,graine,{ia:true})`. Hors démo elles sont désactivées par défaut pour préserver la vitrine du menu. Une IA locale autorisée réagit après un dépassement réel d'un humain, avec hasard privé et temporisations : 8 s par IA, 1,2 s globalement. Le mode démo conserve sa probabilité historique de 0,28 et son délai global de 18 s. Les tests écartent les dépassements IA–IA, les auteurs distants, les replacements/téléportations, les phases invalides et les faux dépassements oscillants. Le hasard du klaxon est séparé de celui du geste ; le hasard et l'état de conduite restent intacts.

Les trois klaxons sont synthétisés dans des buffers préparés (0,42 / 0,56 / 0,96 s). Le budget audio proposé à 00 est **cinq voix fixes**, au lieu des trois du premier contrat : quatre humains simultanés et une IA, dont le délai global dépasse la durée du plus long klaxon. Une seule source est créée par événement accepté sur une voix disponible. Le module respecte le silence et n'active pas implicitement l'audio. Une suspension du contexte arrête et libère immédiatement les voix, sans rejeu au réveil ; la pause normale garde sa courte extinction. La préécoute explicite en pause reste possible.

Le transport en ligne reste à 00 : choix négociés séparément des paquets physiques, validation du couple machine/place locale, événement fiable de début et déduplication session/auteur/pilote/séquence. Ce lot n'ajoute ni transport ni récepteur distant et ne qualifie pas la synchronisation entre machines. Ne pas faire inventer les réactions des auteurs distants par chaque client. Le champ `instant` est un temps local de rendu, pas une horloge réseau commune.
